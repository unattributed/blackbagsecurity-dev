# Security Policy

This repository is a public development-preview deployment repository for Black Bag Security.

## Do not commit sensitive information

Do not commit or publish:

- client or engagement data
- penetration-test evidence
- credentials, passwords, API keys, tokens, cookies, or session material
- private keys, certificates containing private material, or recovery secrets
- confidential reports, contracts, statements of work, or customer communications
- restricted infrastructure details that are not already intended for public disclosure

The development site is intentionally configured with search-engine exclusion directives, but those directives are not access control. Treat every deployed file as public.

## Reporting a security issue

Use the security contact published by Black Bag Security at:

`https://www.blackbagsecurity.com/.well-known/security.txt`

Do not disclose security-sensitive information in a public GitHub issue.
